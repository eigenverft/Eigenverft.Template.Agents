# Assess — Default (Conservative)

Read [Contract.md](Contract.md) first. This is the **Conservative** strategy and the default fallback when no profile or more specific criteria resolve the Assess phase.

## Evaluation Emphasis

Prefer high-confidence, demonstrably useful opportunities with limited consumer disruption, straightforward verification, manageable effort, low regression risk and good reversibility. Reward simplicity, reliability and improvements to established capabilities over speculative expansions.

## Trade-off Rule

When benefit is similar, favor clearer evidence, fewer unknown dependencies and more predictable impact. Do not reject an otherwise valid candidate merely because it changes visible UX, but examine retained capabilities and affected consumer groups.

## Handoff

Explain which eligible candidate best serves the conservative emphasis, why alternatives rank lower and what is still unverified. Follow the common [Assess contract](Contract.md).
