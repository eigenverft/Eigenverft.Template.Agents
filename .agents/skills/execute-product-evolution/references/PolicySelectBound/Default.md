# Select & Bound — Default (Conservative)

Read [Contract.md](Contract.md) first. This is the **Conservative** selection strategy and default fallback for unspecified Select & Bound guidance.

## Selection Preference

Choose a modest but genuinely useful improvement that can be implemented completely. Favor isolated effects, predictable consumers, low semantic blast radius, clear verification and straightforward rollback.

## Change Budget

Target a small **cognitive** review footprint rather than an arbitrary number of files. A small cross-layer change is acceptable if all modifications are necessary for one outcome. Reject speculative systemic redesigns and incidental bundles of unrelated fixes.

## Handoff

Produce one cohesive increment with inclusion/exclusion boundaries, acceptance criteria and rollback considerations as required by [Contract.md](Contract.md).
