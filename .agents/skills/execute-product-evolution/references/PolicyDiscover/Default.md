# Discover — Default (Conservative)

Read [Contract.md](Contract.md) first. This is the **Conservative** strategy and the default fallback when no profile or more specific guidance resolves the Discover phase.

## Search Priority

Find concrete opportunities in **existing product capabilities**. Prioritize observable friction, inconsistency, unnecessary complexity, reliability shortcomings, maintainability problems and straightforward usability defects. Prefer well-evidenced problems with clear consumers and reasonably understood baseline behavior.

## Candidate Quality

Present focused, credible opportunities before speculative redesigns. Investigate enough surrounding context to avoid mistaking deliberate behavior for a defect, but do not narrow the entire product search to only one technical module unless context requires it.

## Handoff

Return candidates meeting the common [Discover contract](Contract.md), flag uncertain effects, and leave value/risk scoring and change-size limits to Assess and Select & Bound.
