# 03 · Investigation

For finding-oriented reviews, **explore relevant directions broadly**, then make promising observations more specific before evaluating them deeply. The V2-style candidate tree is a useful method for doing this; it need not become a written artifact.

- [3.1 Evidence](evidence.md) — reconstruct relevant facts, behavior, context, and paths.
- [3.2 Broad Discovery / Observations & Candidates](observations-candidates.md) — explore multiple plausible investigation directions.
- [3.3 Tree-like Candidate Refinement](candidate-refinement.md) — split broad observations into meaningful subquestions where this helps.
- [3.4 Candidate Shortlist](candidate-shortlist.md) — retain concrete questions worth examining, without treating them as findings.

Move to Evaluation when there are sufficiently concrete questions to assess. Return to discovery when new evidence suggests another relevant direction. A review may have no surviving candidates.

**Migration check:** The instructions encourage useful breadth and clarity before deep evaluation, without forcing quotas, artificial branches, or needless intermediate artifacts.
