# 5.1 Result Selection — Ergebnisbausteine bestimmen

**Responsibility:** Choose which output categories are needed for the specific review and its actual outcome.

During migration:
- Define the review's default outcome type: findings, overall verdict, explanatory synthesis, alternatives, recommended actions, or a justified combination.
- Make supporting details conditional on relevance, rather than producing empty formal sections for every possible category.
- Distinguish a qualified finding from an unresolved observation and from a purely explanatory result.
- Define the expected response when there are zero findings or the review could not cover essential areas.
- Apply user-specified output preferences when compatible with explicit Eigenverft contracts and actual authority.

**Result:** The report contains the necessary and meaningful results, not an artificially completed template.
