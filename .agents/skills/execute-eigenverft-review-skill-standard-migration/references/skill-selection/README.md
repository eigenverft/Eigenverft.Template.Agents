# 01 · Skill Selection

The **review skill being migrated** must communicate its identity and when it applies. This phase selects the appropriate review capability; it does not interpret all specifics of the user's review request.

- [1.1 Identity](identity.md) — establish a distinctive, truthful name and purpose.
- [1.2 Applicability](applicability.md) — define activation criteria and exclusions.

**Migration check:** A reader can determine *which* review this is and *when* to invoke it. Specific target, scope, constraints, and user additions belong to [Review Setup](../review-setup/README.md).
