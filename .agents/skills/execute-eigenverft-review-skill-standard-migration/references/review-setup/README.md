# 02 · Review Setup

Establish the review contract from the actual user request and review-specific knowledge. The parts answer different questions; do not merge them into a vague, undifferentiated "scope" paragraph.

- [2.1 Request Resolution](request-resolution.md) — interpret user intent and available context.
- [2.2 Objective](objective.md) — define the desired insight.
- [2.3 Target](target.md) — identify what is being reviewed.
- [2.4 Scope](scope.md) — define coverage and boundaries.
- [2.5 Context / Revision](context-revision.md) — establish the relevant state.
- [2.6 Authority](authority.md) — establish permitted actions.
- [2.7 Evaluation Lens](evaluation-lens.md) — define the perspective.
- [2.8 Review Basis](review-basis.md) — establish standards and evidence for judgment.
- [2.9 Method Contract](method-contract.md) — establish the applicable investigation/evaluation procedure.

**Migration check:** The review can proceed from explicit user constraints or well-defined defaults without the agent inventing its own narrow task. The authority, method, and output contract govern subsequent phases even when authored here.
