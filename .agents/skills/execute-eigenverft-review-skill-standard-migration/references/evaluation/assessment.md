# 4.2 Assessment — Bedeutung bewerten

**Responsibility:** Evaluate the practical significance of a sufficiently understood situation, not merely whether it looks unusual.

During migration:
- Define review-specific criteria for actual costs, impact, affected users/changes, risks, and likely improvement.
- Assess counterarguments, trade-offs, dependencies, implementation effort, and the possibility that the existing design is preferable.
- Distinguish severity of the concern from urgency, implementation priority, expected benefit, confidence, and effort.
- When the review produces severity-rated findings, use the Eigenverft levels `Critical`, `High`, `Medium`, and `Low`, with definitions adapted to the review domain. Avoid fabricating a severity rating for non-finding outcome types.
- Do not require a proposed fix to be fully implemented or universally optimal for a useful improvement direction to qualify.

**Result:** A reader can understand why an observed problem deserves attention and which uncertainties remain.
