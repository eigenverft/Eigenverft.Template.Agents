# 4.1 Validation

**Responsibility:** Check whether a candidate's factual claim is actually supported.

During migration:
- Ask the target review skill to verify relevant source behavior, access paths, contracts, state transitions, callers, or test outcomes as appropriate.
- Seek material counterevidence and legitimate explanations; naming, style, suspicious syntax, or a possible refactoring alone do not validate a problem.
- Separate observable facts from interpretation, estimated consequences, and hypothetical future changes.
- Revisit Investigation when additional accessible evidence may materially change the conclusion.
- If key evidence remains inaccessible, leave the claim unresolved or conditional and record the actual limitation.

**Result:** Only supported claims proceed to an evidence-grounded assessment.
