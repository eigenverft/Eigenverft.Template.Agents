# 04 · Evaluation

Evaluate the meaningful questions from Investigation against evidence, counterevidence, the review basis, and their practical significance.

- [4.1 Validation](validation.md) — establish which claims are supported.
- [4.2 Assessment](assessment.md) — judge actual impact, trade-offs, and possible improvement.
- [4.3 Decisions](decisions.md) — qualify findings, reject weak candidates, or retain genuine uncertainty.

As Evaluation progresses, follow relevant new leads and revisit material unanswered questions. Continue to Investigation when a new direction is worth exploring; gather further evidence when it could change an assessment. Report supported outcomes when enough relevant work has been done, including a zero-finding result. Explain material gaps that available evidence cannot resolve.

**Migration check:** The review encourages sufficiently broad and deep investigation, without stopping merely because some strong findings have already been identified.
