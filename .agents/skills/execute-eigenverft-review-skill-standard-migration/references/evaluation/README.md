# 04 · Evaluation

Evaluate material candidates and decide what is ready to report. Return to Investigation when evidence could still change a conclusion.

- [4.1 Validation](validation.md) — establish which claims are supported.
- [4.2 Assessment](assessment.md) — judge impact, significance, and trade-offs.
- [4.3 Decisions](decisions.md) — qualify, reject, or leave candidates unresolved; decide whether the review can close.

**Completion path:** Sufficient investigation → Reporting (including zero findings). Further useful, available evidence → Investigation. Material unresolvable gaps → state limitations, then report proportionately.

**Migration check:** Neither the first finding nor a particular severity level silently ends the search; the review has a useful and finite completion rule.
