# Deferred Skills

Ablage für Skills, die sich im praktischen Einsatz als noch nicht zuverlässig oder nicht wie beabsichtigt funktionierend erwiesen haben und deren Überarbeitung vorerst zurückgestellt wird.

Hier können betroffene Skill-Pakete und kurze Hinweise zum beobachteten Problem abgelegt werden, damit sie später gezielt wieder aufgegriffen werden können. Es wird dadurch kein bestehender Skill automatisch verschoben oder deaktiviert.
